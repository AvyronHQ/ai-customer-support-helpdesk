# AI Customer Support & Helpdesk Automation Dashboard

AI-powered customer support portfolio demo with a support dashboard, ticket triage, analytics, searchable Help Center, and interactive AI chatbot.

## Features
- Support KPIs and AI resolution metrics
- Priority ticket queue and ticket inbox
- Searchable Help Center
- Interactive AI chatbot
- Local knowledge-base answers for orders, refunds, billing, accounts, and plans
- Human escalation behavior for unresolved questions
- Responsive UI

## Run
Open `index.html` in a browser. No build tools or API keys are required.

## Portfolio note
The chatbot is a front-end simulation. A production version can connect to an LLM, vector knowledge base, CRM/helpdesk, authentication, and ticket APIs.
